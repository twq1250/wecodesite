布局设计对比

布局 1: Inner 布局（layout: 'inner'）
Header 区域（64px） Logo + 导航 + 用户
AppInfoBar（50px） 应用信息栏
Sidebar（220px）
API管理
事件配置
回调配置
操作日志
分类管理
API管理（Admin）
事件管理
Content 区域

✓ 特点：

  • 包含完整的 Header（顶部导航）
  • 包含 AppInfoBar（应用信息栏）
  • 左侧 Sidebar 菜单导航
  • 适合需要完整应用信息的页面
  • 当前8个Admin页面使用此布局
布局 2: 简洁布局（无 layout 或 layout !== 'inner'）
Sidebar（200px）
API管理
事件配置
回调配置
操作日志
分类管理
API管理（Admin）
事件管理
Content 区域

✓ 特点：

  • 无 Header 区域
  • 无 AppInfoBar
  • 仅保留左侧 Sidebar 菜单
  • 右侧 Content 内容区域
  • 更简洁，适合不需要应用信息的页面

路由配置示例

export default {
  path: '/admin/apis',
  auth: false,
  preload: false,
  isStatic: true,
  key: 'admin-apis',
  layout: 'inner',  // ← 使用 Inner 布局
  component: () => import('./index'),
}
💡 说明：根据路由配置中的 layout 字段自动选择布局：
• layout: 'inner' → 使用完整 Inner 布局（Header + AppInfoBar + Sidebar + Content）
• layout: 其他值 或 无 layout 字段 → 使用简洁布局（Sidebar + Content）
