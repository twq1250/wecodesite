# 首页创建应用功能实施计划

## 需求概述
点击首页的"创建应用"按钮，弹出 Modal 弹窗，填写应用信息后将应用添加到列表中。

## 重要约束
**所有 mock 数据必须通过 thunk 获取，禁止直接在组件中 import mock 数据**

## 需要创建/修改的文件

### 1. 新建组件文件

#### `src/components/CreateAppModal/CreateAppModal.jsx`
创建应用弹窗组件，包含：
- Modal 弹窗容器
- Form 表单（应用图标、中文名称、英文名称、中文描述、英文描述、绑定EAMAP）
- 应用图标：图片上传区域 + 6个默认图标选择
- 绑定到应用服务：下拉选择框

#### `src/components/CreateAppModal/CreateAppModal.m.less`
创建应用弹窗样式

#### `src/components/BindEamapSelect/BindEamapSelect.jsx`
绑定到应用服务通用下拉组件：
- 下拉选择可绑定的EAMAP
- **EAMAP 数据通过 props 传入，不内部获取**

#### `src/components/BindEamapModal/BindEamapModal.jsx`
绑定EAMAP弹窗组件（用于详情页"立即绑定"功能）

### 2. 修改现有文件

#### `src/pages/AppList/AppList.jsx`
- 引入并使用 CreateAppModal 组件
- 通过 thunk (`fetchAppList`) 获取应用列表数据
- 点击"创建应用"按钮打开弹窗
- 创建成功后调用 thunk 刷新列表

#### `src/pages/AppList/thunk.js`
- 添加 `fetchDefaultIcons` 获取默认图标列表（6个）
- 添加 `fetchEamapOptions` 获取 EAMAP 下拉选项数据（10~20条）
- 添加 `createApp` 创建新应用
- 添加 `bindEamap` 绑定EAMAP到应用

#### `src/pages/AppList/mock.js`
- 保留数据定义，供 thunk 调用

#### `src/pages/BasicInfo/BasicInfo.jsx`
- 通过 thunk 获取/更新应用信息
- 引入 BindEamapModal 组件
- 当应用未绑定时，显示"立即绑定"按钮
- 点击按钮打开绑定弹窗，绑定成功后更新状态

#### `src/pages/BasicInfo/thunk.js`
- 添加 `bindEamapToApp` 绑定EAMAP到应用的方法

## 任务拆解

### Task 1: 修改 AppList thunk 添加数据获取方法
**文件**: `src/pages/AppList/thunk.js`
**步骤**:
1. 添加 `fetchDefaultIcons` 返回默认图标数组（6个emoji）
2. 添加 `fetchEamapOptions` 返回10~20条EAMAP选项
3. 添加 `createApp` 创建新应用并返回更新后的列表
4. 添加 `bindEamap` 绑定EAMAP到指定应用

### Task 2: 创建 BindEamapSelect 通用组件
**文件**: `src/components/BindEamapSelect/BindEamapSelect.jsx`
**步骤**:
1. 创建 Select 下拉组件
2. 通过 props 接收 eamapOptions 数据
3. 支持 value 和 onChange props

### Task 3: 创建 CreateAppModal 组件
**文件**: `src/components/CreateAppModal/CreateAppModal.jsx`
**步骤**:
1. 创建 CreateAppModal 组件，接收 visible, onCancel, onOk, defaultIcons, eamapOptions props
2. 实现 Form 表单，包含所有必填和选填字段
3. 实现应用图标上传功能（点击上传本地图片）
4. 实现默认图标选择功能（6个图标）
5. 引入 BindEamapSelect 组件作为绑定EAMAP下拉框

### Task 4: 创建 CreateAppModal 样式
**文件**: `src/components/CreateAppModal/CreateAppModal.m.less`
**步骤**:
1. 编写图标上传区域样式
2. 编写默认图标网格样式
3. 编写表单布局样式

### Task 5: 创建 BindEamapModal 弹窗组件
**文件**: `src/components/BindEamapModal/BindEamapModal.jsx`
**步骤**:
1. 创建 Modal 弹窗组件
2. 内部使用 BindEamapSelect 组件
3. 接收 appId, visible, onCancel, onOk, eamapOptions props

### Task 6: 修改 AppList 页面集成创建应用功能
**文件**: `src/pages/AppList/AppList.jsx`
**步骤**:
1. 引入 CreateAppModal 组件
2. 使用 `fetchAppList`, `fetchDefaultIcons`, `fetchEamapOptions` thunk 获取数据
3. 添加 useState 管理弹窗显示
4. 点击"创建应用"按钮打开弹窗
5. 实现 onOk 回调，调用 `createApp` thunk 创建新应用

### Task 7: 修改 BasicInfo thunk 添加绑定方法
**文件**: `src/pages/BasicInfo/thunk.js`
**步骤**:
1. 添加 `bindEamapToApp` 方法

### Task 8: 修改 BasicInfo 页面添加立即绑定功能
**文件**: `src/pages/BasicInfo/BasicInfo.jsx`
**步骤**:
1. 引入 BindEamapModal 组件
2. 通过 thunk 获取/更新应用信息
3. 获取当前应用的 eamap 绑定状态
4. 当 eamap 为 null 时，显示"立即绑定"按钮
5. 点击按钮打开绑定弹窗
6. 绑定成功后调用 thunk 更新应用状态

## 实施顺序
1. Task 1 (AppList thunk) - 先完善数据层
2. Task 2 (BindEamapSelect) - 被其他组件依赖
3. Task 3 (CreateAppModal)
4. Task 4 (CreateAppModal 样式)
5. Task 5 (BindEamapModal)
6. Task 6 (AppList 修改)
7. Task 7 (BasicInfo thunk)
8. Task 8 (BasicInfo 修改)
