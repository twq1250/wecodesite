# 凭证和基础信息页面修改计划

## 修改概述

将凭证和基础信息页面改为：
1. 移除页面底部的保存和取消按钮
2. 基础信息区域和认证方式区域各自独立编辑
3. Form表单layout改为horizontal，label长度一致
4. 进入页面时两个区域都处于详情态，点击编辑按钮进入编辑态，底部显示取消和保存按钮

## 详细代码修改

### Task 1: 状态管理

在组件内添加：
```jsx
const [basicInfoEditing, setBasicInfoEditing] = useState(false);
const [authMethodEditing, setAuthMethodEditing] = useState(false);
const [basicInfoForm] = Form.useForm();
const [authMethodForm] = Form.useForm();
```

### Task 2 & 3: 区域重构

基础信息区域结构：
```
Card
  - Header: 标题 + 编辑按钮（详情态显示）/ 保存+取消按钮（编辑态显示）
  - Body:
    - 详情态: 文本展示（应用图标、中文名称、英文名称、中文描述、英文描述、功能示意图）
    - 编辑态: horizontal Form 表单
```

认证方式区域结构：
```
Card
  - Header: 标题 + 编辑按钮（详情态显示）/ 保存+取消按钮（编辑态显示）
  - Body:
    - 详情态: Radio 选项（disabled）
    - 编辑态: horizontal Form 表单
```

### Task 4: 移除底部按钮

删除：
```jsx
<Space>
  <Button type="primary" onClick={handleSave}>保存</Button>
  <Button>取消</Button>
</Space>
```

## 验证方式

1. 页面加载后，基础信息和认证方式都显示为详情态
2. 点击基础信息的编辑按钮，切换到编辑态，显示取消和保存按钮
3. 点击认证方式的编辑按钮，切换到编辑态，显示取消和保存按钮
4. 两个区域的编辑状态相互独立
5. 表单布局为 horizontal，label 对齐
6. 页面底部无保存取消按钮
7. 表单验证正常工作
