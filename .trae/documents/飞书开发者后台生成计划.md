# 飞书开发者后台生成计划

## 项目概述

创建一个类似飞书开放平台的开发者后台管理系统，包含应用列表页和应用详情页两个主要模块。

## 页面结构

### 1. 应用列表页（首页）

- 展示所有已创建的应用卡片列表
- 每个卡片显示：应用图标、应用名称、应用状态、创建时间
- 包含"创建新应用"按钮
- 点击卡片进入应用详情页

### 2. 应用详情页

包含以下子页面，通过侧边栏切换：

#### 2.1 凭证和基础信息页

- 应用图标和名称编辑
- 应用描述
- 应用凭证（App ID、App Secret）
- 安全配置

#### 2.2 成员管理

- 成员列表
- 添加/移除成员
- 成员角色设置

#### 2.3 添加应用能力

- 能力市场
- 已启用能力列表
- 能力配置

#### 2.4 API管理

- API列表
- API配置
- 接口调试

#### 2.5 事件与回调

- 事件列表
- 回调配置
- 事件订阅

#### 2.6 版本发布

- 版本历史
- 发布管理
- 版本对比

## 布局结构

### 全局布局

```
┌─────────────────────────────────────────────────┐
│               Header (顶部导航)                │
├─────────────────────────────────────────────┤
│        应用信息栏（应用详情页显示）           │
├──────────┬──────────────────────────────────┤
│  侧边栏   │           主内容区               │
│ (导航菜单)│                                │
│          │                                │
│          │                                │
└──────────┴──────────────────────────────────┘
```

Header 和应用信息栏都各占一整行，应用信息栏仅在应用详情页显示

### 设计规范

- 风格：参照飞书开放平台，简洁专业
- 配色：蓝色主色调，白色背景，灰色辅助
- 字体：使用系统性字体
- 间距：16px 基础网格

## 交互方式

1. 首页点击应用卡片 → 进入详情页
2. 详情页通过左侧侧边栏切换子页面
3. 顶部面包屑可返回上一级

## 技术方案

### 技术栈选择

- React + JavaScript (React 18.2.0)
- 使用 LESS 作为样式文件
- 样式文件统一命名为 style.m.less 或 \*.m.less
- 路由：React Router (6.20.0)
- UI组件库：Ant Design (4.24.16)
- 构建工具：Vite (5.0.0)

### 文件类型说明

| 文件类型       | 说明                |
| ---------- | ----------------- |
| `*.jsx`    | React 组件文件        |
| `*.js`     | JavaScript 文件     |
| `*.m.less` | Less 样式文件（m表示模块化） |
| `mock.js`  | 模拟数据文件            |
| `thunk.js` | 异步数据获取函数，模拟API调用  |
| `route.js` | 路由配置，定义页面路径和名称    |

## 实现步骤

### Step 1: 项目基础设置

- 创建 React + JavaScript 项目 (Vite)
- 安装依赖（react-router-dom, antd, @ant-design/icons, less）
- 设置全局样式和主题

### Step 2: 布局组件开发

- Layout 主布局容器，处理条件渲染
- Header 顶部导航组件
- Sidebar 侧边栏导航组件
- AppInfoBar 应用信息栏组件

### Step 3: 应用列表页开发

- AppCard 应用卡片组件
- AppList 页面
- mock.js 模拟数据
- thunk.js 异步数据函数

### Step 4: 应用详情页开发

- AppInfoBar 在详情页显示逻辑
- 侧边栏导航到各子页面
- 路由配置

### Step 5: 各子页面功能实现

- BasicInfo 凭证和基础信息页
- Members 成员管理页
- Capabilities 添加应用能力页
- CapabilityDetail 能力详情页
- ApiManagement API管理页 + ApiPermissionDrawer
- Events 事件与回调页 + EventDrawer
- VersionRelease 版本发布页

### Step 6: 样式优化和交互完善

- 样式细节调整
- 动画和过渡效果
- 响应式适配

## 验收标准

1. 应用列表页正常显示应用卡片列表
2. 点击卡片可进入详情页
3. 侧边栏可切换子页面
4. 布局符合飞书开放平台风格
5. 页面交互流畅
