# 计划：添加操作日志子界面

## 需求概述
在左侧菜单添加"运营监控"模块（位于开发配置下、版本管理上），包含"操作日志"子界面，用于展示用户操作记录。

## 实施步骤

### 步骤1：修改 Sidebar 菜单配置
在 `src/components/Layout/Sidebar/Sidebar.jsx` 的 dynamicMenuItems 中添加"运营监控"模块：
- 位置：开发配置与版本管理之间
- 图标：使用 `LineChartOutlined` 或类似图表图标
- 子菜单：操作日志 (operation-log)

### 步骤2：创建操作日志页面目录和文件
在 `src/pages/` 下创建 `OperationLog` 目录，包含：
- `OperationLog.jsx` - 主页面组件
- `OperationLog.m.less` - 样式文件

### 步骤3：实现 OperationLog.jsx 页面组件
页面从上到下包含：
1. **页面标题**：操作日志
2. **搜索区域**（一行，左右布局）：
   - 左侧：操作账号（输入框）、操作对象（下拉框）、操作时间（开始、结束日期选择器）
   - 右侧：重置、查询按钮
3. **操作记录表格**：
   - 表头列：操作账号、操作类型、操作对象、操作描述、操作IP、操作时间、操作结果
   - 使用 antd Table 组件
4. **分页器**（左右布局）：
   - 左侧：固定文案"最近180日数据"
   - 右侧：antd Pagination 组件，分页大小可选10、20、50，默认10

### 步骤4：注册路由
在 `src/App.jsx` 中添加路由：
```jsx
<Route path="operation-log" element={<OperationLog />} />
```

### 步骤5：侧边栏图标引入
在 Sidebar.jsx 中引入需要的图标（如 `LineChartOutlined`）

需要修改/创建的文件：
